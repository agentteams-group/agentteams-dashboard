# Avatar artwork

The 18 Pixelbot, Open Peeps and Shapes PNGs were generated as 128 × 128 avatars using the DiceBear 10.x HTTP API. Each series uses the seeds `acorn`, `copper`, `jade`, `lotus`, `pebble`, and `sprout`, in that order.

| Series | Artwork | License |
| --- | --- | --- |
| [Pixelbot](https://www.dicebear.com/styles/pixelbot/) | DiceBear | CC0 1.0 |
| [Open Peeps](https://www.dicebear.com/styles/open-peeps/) | Pablo Stanley, adapted by DiceBear | CC0 1.0 |
| [Shapes](https://www.dicebear.com/styles/shapes/) | DiceBear | CC0 1.0 |

The application serves these files locally.

## 模型娘 · Worker portraits

The eight `model-girl-*.png` files are 256 × 256 portraits for the Worker avatar picker. The illustrations were created with ImageGen and draw on community character designs by zipzip. [Community character reference](https://www.bilibili.com/video/BV1tE9XBbErS/)

`model-girl-deepseek.png` adapts the whale girl character by 上善无形 and zipzip’s “大肥鱼” artwork into a close-up holding a rice bowl. This illustration is distributed under CC BY-NC-SA 4.0.
