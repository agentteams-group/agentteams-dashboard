# Avatar artwork

The 18 PNGs were generated as 128 × 128 avatars using the DiceBear 10.x HTTP API. Each series uses the seeds `acorn`, `copper`, `jade`, `lotus`, `pebble`, and `sprout`, in that order.

| Series | Artwork | License |
| --- | --- | --- |
| [Pixelbot](https://www.dicebear.com/styles/pixelbot/) | DiceBear | CC0 1.0 |
| [Open Peeps](https://www.dicebear.com/styles/open-peeps/) | Pablo Stanley, adapted by DiceBear | CC0 1.0 |
| [Shapes](https://www.dicebear.com/styles/shapes/) | DiceBear | CC0 1.0 |

The application serves these files locally.
