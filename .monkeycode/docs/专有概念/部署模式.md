# 部署模式

`use-deployment-mode.ts` 按环境覆盖、Controller `kubeMode` 和文件系统回退的优先级计算 `embedded` 或 `k8s`。`AGENTTEAMS_DEPLOYMENT_MODE` 与 `AGENTTEAMS_KUBE_MODE` 可提供部署环境覆盖值。

该模式控制 UI 的平台能力呈现：一级 `ops` 导航项仅在 `k8s` 模式显示。Controller 资源 API 保持相同代理入口。

## Standalone vs Shared

Dashboard 在多用户共享部署（`DASHBOARD_SHARED_MODE=1`）下收紧以下行为，Standalone（默认，单实例单人）则保留宽容行为：

- 会话密钥（`DASHBOARD_SESSION_SECRET`）：Standalone 启动时若缺失则在 `/data/agentteams-dashboard/.session-secret` 生成并落盘（mode 0600，仅 stderr 输出末四位）；Shared 模式下必须显式设置环境变量，缺源时直接 fail-closed，避免共享主机上隐式共享同一密钥。
- 后端配置写权限（`/api/agentteams/setup/backends`）：Standalone 任意已登录用户可写（plugin parity）；Shared 仅 L3（admin）可写，防止任意 L2 用户把全实例数据面重定向到伪造后端。
- 审计写入：Standalone 模式下日志仍记录 actor/level/source_ip；Shared 模式下 `/api/agentteams/setup/backends` 与 `/api/matrix/rooms/[roomId]/join|leave` 的写动作都走 `appendAuditEvent`，供治理审计页面追溯。
