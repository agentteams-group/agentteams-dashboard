# 模型别名绑定

Worker 与 Manager 的 `model` 字段是发送给 Higress Gateway 的请求模型别名，例如 `team-chat`。`src/lib/model-bindings.ts` 将别名与 AI Route、Route upstream、Provider Token 状态和目标模型计算为可用性结果。

external 模式下，Gateway 数据平面地址来自 `AGENTTEAMS_AI_GATEWAY_URL`，Console 管理地址是独立配置。Dashboard 在创建、更新或启动相关操作中验证模型别名；没有可用绑定时返回 `409`，避免运行时请求落到无法解析的模型配置。
