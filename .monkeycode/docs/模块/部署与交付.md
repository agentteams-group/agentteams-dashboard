# 部署与交付模块

`Dockerfile` 使用多阶段构建产生 Next standalone 镜像。`next.config.ts` 启用 standalone 输出、严格模式、尾随斜杠和可选 `NEXT_PUBLIC_BASE_PATH`。运行镜像监听 3000，并以 UID 1001 的 `nextjs` 用户运行。

`install/agentteams-dashboard.sh` 负责容器安装、更新、Controller token 获取和健康检查；默认创建 `agentteams-dashboard` 容器并映射 `127.0.0.1:13000:3000`。`agentteams-dashboard.ps1` 提供 PowerShell 入口，安装验证脚本检查 Bash、PowerShell、补丁和容器运行。

`install/patches/` 与 `install/AGENTTEAMS_PATCH.md` 维护固定 AgentTeams 提交的补丁顺序。外部 Higress 补丁约定将 `AGENTTEAMS_AI_GATEWAY_URL` 和请求模型别名传入 Controller、Manager 与 Worker。

`.github/workflows/build.yml` 发布多架构镜像；`install-test.yml` 为安装相关 PR 执行验证。应用质量命令为 `npm run lint`、`npm run typecheck`、`npm test` 和 `npm run build`。
