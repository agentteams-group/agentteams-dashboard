# 技能中心模块

技能中心负责 AgentTeams 中技能的全生命周期管理：存储、上传、Nacos 同步、下载与分发到 Worker。

## 结构

```
src/app/api/agentteams/skills/
  route.ts                 技能列表 (GET) 与上传 (POST)
  [name]/route.ts          单个技能读取、更新、删除
  [name]/download/route.ts 下载技能 ZIP
  nacos/
    [name]/download/route.ts Nacos 技能下载（含缓存）
    config/route.ts         Nacos 注册中心配置
    sync/route.ts           触发 Nacos 技能同步

src/lib/
  skill-center-types.ts    类型定义 (SkillEntry, NacosConfig 等)
  skill-center-storage.ts  MinIO 存储操作 (元数据/文件/全局技能)
  skill-center-config.ts   Nacos 配置持久化
  skill-package.ts         技能包 ZIP 解析与校验

src/components/dashboard/sections/skills/
  skill-center.tsx          技能列表主页（搜索、筛选、刷新）
  skill-upload-dialog.tsx   上传对话框（含冲突检测与覆盖确认）
  skill-edit-dialog.tsx     编辑技能元数据
  skill-detail-dialog.tsx   技能详情与文件列表
  skill-distribute-dialog.tsx 分发技能到 Worker
  skill-selector.tsx        多选技能组件
  nacos-config-dialog.tsx   Nacos 配置对话框
  index.ts                  公开导出

src/hooks/
  use-skill-center.ts       技能 CRUD hook
  use-nacos-config.ts       Nacos 配置与同步 hook
```

## 关键文件

| 文件 | 目的 |
|------|------|
| `skill-center-types.ts` | 所有技能相关的 TypeScript 类型和常量定义 |
| `skill-center-storage.ts` | MinIO 上技能元数据和文件内容的管理操作 |
| `skill-package.ts` | 技能 ZIP 包解析，提取 `skill.md` frontmatter 元数据 |
| `skill-center.tsx` | 技能中心主页面，集成搜索、来源筛选和分页 |
| `skill-upload-dialog.tsx` | 上传流程：检测名称冲突、展示已有信息、确认覆盖 |

## 规范

### 技能来源

| 来源 | 标识 | 存储位置 | 可否覆盖 |
|------|------|----------|----------|
| 自定义上传 | `custom` | MinIO `skills/` bucket | 可（需 `overwrite=true`） |
| Nacos 同步 | `nacos` | 元数据在 MinIO，内容按需从 Nacos 拉取 | 不可（返回 403） |
| 全局内置 | `builtin` | 主 bucket `agents/global/skills/` 前缀 | 不可 |

### 文件命名

- 类型定义：`skill-center-types.ts`
- 存储操作：`skill-center-storage.ts`
- 配置管理：`skill-center-config.ts`
- 组件：`skill-[feature].tsx`
- 测试：`[file].test.ts`（同目录）

### 错误处理

- MinIO 未配置：返回 503，提示配置信息
- 技能名冲突：返回 409，附带现有技能元数据供 UI 展示
- Nacos 不可达：返回 502，附带具体错误信息
- Nacos 技能不可覆盖：返回 403
- 文件超过 64MB 限制：返回 400

### 代码模式

**技能列表合并逻辑**（`GET /skills`）：
```
globalSkills (builtin) + metadataSkills (custom/nacos)
→ 同名时 metadataSkills 优先 → source 过滤 → 搜索过滤 → 分页
```

**Nacos 技能下载缓存策略**：
```
1. 检查 MinIO {name}/ 前缀下是否有文件 → 有则直接打包返回
2. 无缓存 → 根据 config.mode 从 Nacos 拉取
3. 拉取成功 → 缓存到 MinIO → 返回 ZIP
4. 拉取失败 → 返回 502
```

**Worker 技能安装流程**：
```
skillNames[] → for each: downloadSkill() → 403? → downloadNacosSkill() → uploadWorkerSkill()
失败不阻塞，toast 警告
```
