# Dashboard 导航清理需求

## 引言

本功能收敛 Dashboard 导航和资源中心入口，减少重复入口并将文档固定在侧边栏底部。

## 术语表

- **市场**：资源中心中管理技能内容的入口。
- **底部入口**：侧边栏主导航之后、折叠控件之前呈现的导航项。

## 需求

### 需求 1：资源中心入口

**用户故事：** 作为 Dashboard 操作员，我希望通过统一资源中心管理市场和 MCP 服务器，以便避免重复导航入口。

#### 验收标准

1. Dashboard SHALL 将技能入口标签呈现为市场。
2. Dashboard SHALL 在资源中心呈现市场和 MCP 服务器标签。
3. Dashboard SHALL 在资源中心隐藏 Worker 运行标签。

### 需求 2：导航收敛

**用户故事：** 作为 Dashboard 操作员，我希望侧边栏仅呈现可访问的管理入口，以便聚焦日常操作。

#### 验收标准

1. Dashboard SHALL 从主导航移除 MCP 服务器入口。
2. Dashboard SHALL 从主导航移除运维中心入口。
3. Dashboard SHALL 将文档入口呈现在侧边栏底部。
