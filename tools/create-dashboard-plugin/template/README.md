# {{PLUGIN_NAME}}

AgentTeams Dashboard 插件（由 `create-dashboard-plugin` 生成）。

## 快速开始（3 分钟）

```bash
npm install
npm run dev        # 启动插件开发服务器 http://localhost:5173
```

然后在 Dashboard 中加载插件，两种方式任选其一：

1. **界面安装**：打开 Dashboard「设置 → 插件 → 从 URL 安装」，填入
   `http://localhost:5173/plugin.json`，点击安装。
2. **环境变量**：Dashboard 启动前设置
   `NEXT_PUBLIC_PLUGIN_DEV_URLS=http://localhost:5173/plugin.json`。

安装后侧边栏会出现「{{PLUGIN_NAME}}」菜单项，总览页会出现一个示例组件。

## 开发循环

- 修改 `src/main.jsx` 后保存。Dashboard 开发模式会轮询插件入口，
  检测到内容变化后自动重新加载插件（无需刷新页面）。
- 插件与 Dashboard 共享同一个 React 实例（通过
  `window.__AGENTTEAMS_DASHBOARD_HOST__`），因此 Hooks/Context 正常工作。
- `vite.config.mjs` 中的 `dashboard-host-react` 插件负责把
  `react` / `react-dom` / `react/jsx-runtime` 解析到宿主 React，
  请勿将 React 打包进插件产物。

## 插件结构

```
public/plugin.json    插件清单（id/版本/入口/扩展点声明）
src/main.jsx          入口：activate(api) / deactivate()
```

## 可用 API（activate 参数）

| API | 说明 |
| --- | --- |
| `api.registerMenuItem(item)` | 侧边栏菜单项（扩展点 sidebar-menu） |
| `api.registerRoute(route)` | 独立页面（扩展点 route） |
| `api.registerWidget(widget)` | 总览页仪表盘组件（扩展点 dashboard-widget） |
| `api.registerDetailBlock(block)` | 详情面板区块（扩展点 detail-panel） |
| `api.registerToolbarButton(btn)` | 顶栏工具按钮（扩展点 toolbar） |
| `api.events.on/off/emit` | 事件总线（插件间通信） |
| `api.store.getState/setState/subscribe` | 插件独立持久化状态 |
| `api.http.get/post/fetch` | 带 basePath 的请求封装 |
| `api.dashboard.*` | 集群数据、导航、Toast |
| `api.log.info/warn/error` | 带插件前缀的日志 |

完整文档见 Dashboard 仓库 `docs/plugin-development.zh-CN.md`。

## 构建发布

```bash
npm run build      # 输出 dist/main.js（ES 模块）
```

将 `dist/` 与 `plugin.json`（`entry.dashboard` 改为 `dist/main.js`）
部署到任意静态服务器，再把清单 URL 安装到 Dashboard 即可。
