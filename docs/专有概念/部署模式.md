# 部署模式

`use-deployment-mode.ts` 按环境覆盖、Controller `kubeMode` 和文件系统回退的优先级计算 `embedded` 或 `k8s`。`AGENTTEAMS_DEPLOYMENT_MODE` 与 `AGENTTEAMS_KUBE_MODE` 可提供部署环境覆盖值。

该模式只影响两处呈现，不改变导航结构：连接状态条在 `k8s` 模式追加 Kubernetes 健康项（`connection-status.tsx`），总览页按模式显隐健康卡片——MinIO 卡仅在 `embedded` 显示，Higress 与 Kubernetes 卡在 `embedded` 隐藏（`overview-section.tsx`）。Controller 资源 API 保持相同代理入口。
