# 部署与交付模块

`Dockerfile` 使用多阶段构建产生 Next standalone 镜像。`next.config.ts` 启用 standalone 输出、严格模式、尾随斜杠和可选 `NEXT_PUBLIC_BASE_PATH`。运行镜像监听 3000，并以 UID 1001 的 `nextjs` 用户运行。

`install/agentteams-dashboard.sh` 负责容器安装、更新、Controller token 获取和健康检查；默认创建 `agentteams-dashboard` 容器并映射 `127.0.0.1:13000:3000`（`AGENTTEAMS_LOCAL_ONLY=0` 可改为暴露 `0.0.0.0:13000`）。安装脚本当前默认镜像标签为 `v1.4.1`（`DEFAULT_DASHBOARD_VERSION`，与 `package.json` 的 `version` 一致），可通过 `AGENTTEAMS_DASHBOARD_VERSION` 显式选择。`agentteams-dashboard.ps1` 提供 PowerShell 入口。

`install/agentteams-verify.sh` 是安装后浅验证：检测 Docker/Podman 运行时，对 `agentteams-manager` 容器执行 7 项只读连通性检查（Manager 容器、MinIO health、Matrix API、Higress Gateway、Higress Console、Manager Agent 健康、Dashboard 可达），逐项输出 PASS/FAIL。Bash 语法与 PowerShell AST 校验不在该脚本内，由 `install-test.yml` 的安装测试作业完成。

Dashboard 与 AgentTeams 安装器的集成已通过 [PR #1075](https://github.com/agentscope-ai/AgentTeams/pull/1075) 合入上游；`install/AGENTTEAMS_PATCH.md` 记录运行时合同与接口边界，后续上游变更一律通过 PR 提交到 `agentscope-ai/AgentTeams`（基于补丁文件的流程已废弃）。外部 Higress 模式约定将 `AGENTTEAMS_AI_GATEWAY_URL` 和请求模型别名传入 Controller、Manager 与 Worker，参考实现保存在本仓库 `install/agentteams-install.sh` 与 `install/agentteams-dashboard.sh`。

## 镜像构建

`Makefile` 是本地构建与推送的唯一入口：

| 目标 | 说明 |
|---|---|
| `make build` | 构建本机架构镜像 |
| `make tag` | 构建并打 registry 标签 |
| `make push` | 多架构（amd64 + arm64）构建并推送，依赖 `buildx-setup` |
| `make push-platform` / `make push-native` | 只推送单一平台（`push-native` 会覆盖多架构镜像，仅用于本地开发） |
| `make push-manifest` | 把已完成的 amd64/arm64 镜像合并为一个 manifest；CI 的 merge 作业即调用此目标 |
| `make buildx-setup` / `make buildx-upgrade` | 准备或升级多架构 builder |
| `make clean` | 删除本地镜像 |

`.github/workflows/` 共 5 个工作流：

| 工作流 | 触发与职责 |
|---|---|
| `build.yml` | 多架构矩阵构建（amd64/arm64）+ manifest 合并，发布 `vX.Y.Z` 与 `latest` 双 tag |
| `install-test.yml` | `install/**` 变更时执行安装相关验证（含 Bash/PowerShell 语法校验） |
| `ci.yml` | Lint / Typecheck / 单元测试 / 镜像发布测试 + 文档一致性门禁 |
| `ci-alert.yml` | `main` 分支 CI 失败时自动开 issue |
| `upstream-drift.yml` | 比对 `install/` 与上游 AgentTeams 安装器的漂移 |

应用质量命令为 `npm run lint`、`npm run typecheck`、`npm test` 和 `npm run build`。
