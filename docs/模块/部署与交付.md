# 部署与交付模块

`Dockerfile` 使用多阶段构建产生 Next standalone 镜像。`next.config.ts` 启用 standalone 输出、严格模式、尾随斜杠和可选 `NEXT_PUBLIC_BASE_PATH`。运行镜像监听 3000，并以 UID 1001 的 `nextjs` 用户运行。

`install/agentteams-dashboard.sh` 负责容器安装、更新、Controller token 获取和健康检查；默认创建 `agentteams-dashboard` 容器并映射 `127.0.0.1:13000:3000`。安装脚本当前默认镜像标签为 `v1.3.1`，可通过 `AGENTTEAMS_DASHBOARD_VERSION` 显式选择。`agentteams-dashboard.ps1` 提供 PowerShell 入口，安装验证脚本检查 Bash、PowerShell 和容器运行。

Dashboard 与 AgentTeams 安装器的集成已通过 [PR #1075](https://github.com/agentscope-ai/AgentTeams/pull/1075) 合入上游；`install/AGENTTEAMS_PATCH.md` 记录运行时合同与接口边界，后续上游变更一律通过 PR 提交到 `agentscope-ai/AgentTeams`（基于补丁文件的流程已废弃）。外部 Higress 模式约定将 `AGENTTEAMS_AI_GATEWAY_URL` 和请求模型别名传入 Controller、Manager 与 Worker，参考实现保存在本仓库 `install/agentteams-install.sh` 与 `install/agentteams-dashboard.sh`。

`.github/workflows/build.yml` 发布多架构镜像；`install-test.yml` 为安装相关 PR 执行验证。应用质量命令为 `npm run lint`、`npm run typecheck`、`npm test` 和 `npm run build`。
